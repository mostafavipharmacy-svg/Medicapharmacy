# مدیکا فارماسی | Medica Pharmacy — MVP نمایشی

این پروژه یک PWA موبایل‌محورِ فارسی/انگلیسی، بدون build step و بدون CDN است. **تمام نام‌ها و محتوای دارویی داخل برنامه ساختگی و DEMO هستند. این برنامه برای استفاده پزشکی واقعی نیست و تشخیص، توصیه درمانی یا دستور مصرف نمی‌دهد.** ابزار بررسی تداخل نیز صرفاً یک قانون نمایشی غیر‌بالینی است.

## اجرا و نصب

1. ZIP را استخراج کنید. در پوشه پروژه اجرا کنید:
   ```bash
   python -m http.server 8000
   ```
2. مرورگر را به `http://localhost:8000` باز کنید. `file://` برای Service Worker و نصب PWA کار نمی‌کند. برای دستگاه‌های دیگر لازم است سایت روی HTTPS میزبانی شود (localhost استثناست).
3. **Android:** با Chrome باز کنید و از اعلان/منوی ⋮ گزینه Install app یا Add to Home screen را بزنید.
4. **iPhone/iPad:** با Safari باز کنید، Share را بزنید و Add to Home Screen را انتخاب کنید.

این ZIP **APK نیست**؛ برای نصب PWA به روش بالا استفاده می‌شود. سرویس‌ورکر پوسته را cache می‌کند؛ داده‌های نمایشی فقط زمانی آفلاین‌اند که پیش‌تر دریافت/ذخیره شده باشند. بسته سفرِ دانلودی JSON نمونه است.

## قابلیت‌ها

- خانه، جست‌وجوی رکوردهای ساختگی، جزئیات چندبخشی دارو، داروهای ذخیره‌شده، یادداشت حساسیت، صفحه مسافر و پروفایل.
- تغییر زبان فارسی/English از دکمه نوار بالا و تنظیمات پروفایل؛ انتخاب در اولین استفاده به‌صورت فارسی پیش‌فرض است.
- ذخیره محلی در `localStorage`، خروجی JSON داده‌های محلی و دانلود بسته سفر نمونه.
- ابزار مدیریت محتوای محلی برای ایجاد/ویرایش/حذف رکورد **DEMO ONLY**.
- manifest، آیکن SVG، اعلان نصب در مرورگرهای پشتیبان و پوسته آفلاین.

## امنیت، داده و تولید

پروفایل/ورود این دموی دستگاهی **احراز هویت امن نیست**، گذرواژه/حساب سرور ندارد و داده‌های محلی ممکن است توسط کاربر دستگاه یا مرورگر قابل مشاهده باشند. در تولید، احراز هویت واقعی به backend امن، TLS، مدیریت نشست و مجوزها نیاز دارد. داده دارویی واقعی باید از منابع رسمیِ دارای مجوز، با بررسی داروساز/حاکمیت محتوا، نسخه‌بندی و فرایند اصلاح/بازبینی تأمین شود. قبل از چنین آماده‌سازی‌ای، هیچ محتوای دارویی واقعی اضافه نکنید. هیچ منبع دارای حق نشر خارجی در این نمونه کپی نشده است.

## چک‌لیست پذیرش / عیب‌یابی

- [ ] سرور HTTP اجرا می‌شود و صفحه اصلی در `http://localhost:8000` باز می‌شود.
- [ ] فارسی به‌شکل RTL و English به‌شکل LTR دیده می‌شود؛ تغییر زبان در سربرگ/پروفایل کار می‌کند.
- [ ] جست‌وجو، تب‌های جزئیات، افزودن/حذف دارو، یادداشت محلی و قانون نمایشی تداخل کار می‌کنند.
- [ ] کشور انتخاب و فایل JSON بسته سفر دانلود می‌شود؛ خروجی داده کاربر نیز قابل دانلود است.
- [ ] رکورد DEMO ONLY در ابزار مدیریت ایجاد، ویرایش و حذف می‌شود.
- [ ] با HTTPS یا localhost، Service Worker ثبت می‌شود؛ DevTools → Application وضعیت manifest/cache را نشان می‌دهد.
- [ ] اندازه صفحه موبایل/دسکتاپ و استفاده با صفحه‌کلید بررسی می‌شود.
- [ ] پیام‌های هشدار پزشکی و «NOT CLINICAL» قابل مشاهده‌اند.

اگر Service Worker فعال نشد، از localhost/HTTPS استفاده کنید، نه `file://`؛ cache مرورگر را پاک و صفحه را بازخوانی کنید.
